PACOTE DE ATUALIZAÇÃO - TEL T&D V2

Este pacote contém uma atualização visual e estrutural da base do portal
para a versão atual estabilizada, com foco em:

- layout mais executivo
- dashboard com cards melhores
- página inicial mais organizada
- shell de navegação reutilizável
- serviço de API padronizado

Arquivos incluídos:
- frontend/app/layout.js
- frontend/app/page.js
- frontend/app/inicio/page.js
- frontend/app/dashboard/page.js
- frontend/components/PortalShell.js
- frontend/components/StatCard.js
- frontend/services/api.js

Como aplicar:
1. Baixe este pacote.
2. No GitHub, substitua os arquivos pelos equivalentes do pacote.
3. Faça commit.
4. Aguarde o deploy da Vercel.
5. Teste o login e o dashboard.

Observação:
Este pacote foi preparado para servir como base da versão 2.0.
Depois dele, a ideia é evoluir página por página.
