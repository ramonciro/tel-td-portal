Arquivos para upload da página Sebrae com importação de Excel pelo navegador.

1. Coloque o arquivo em:
app/apresentacao/sebrae/page.js

2. Instale a dependência:
npm install xlsx

3. Faça o deploy.

4. Acesse:
/apresentacao/sebrae

A página lê a aba Base_Dados do Excel diretamente no navegador e não toca nos dados do portal principal.
